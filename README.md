# ESP32-Environmental-Monitor

ESP32 based sensor node that measures temperature, humidity, air pressure and light, showing all the readings on an OLED display and logging data over Wi-Fi to a python script ran from my laptop.
I am building this as a hardware project over the summer holidays ahead of my first year in Electrical Engineering at Monash University.

# HARDWARE #
 - ESP-32 Dev Board (ESP-WROOM-32)
 - Adafruit BME 280 (Temperature, Humidity, Pressure Sensor)
 - BH1750 (Light Sensor)
 - 0.96" SSD1306 I2C OLED
 - Breadboard and Jumper Wires

# PROCESS #
 - Prototype Breadboard
 - Sensor Readings over Serial
 - OLED Data Display
 - Wi-Fi Data Logging
 - Design Custom PCB in KiCad
 - Power Measurement and Battery Operation
